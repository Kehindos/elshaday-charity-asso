1. Executive Summary & Project Purpose

Elshaday Charity Organization (ኤልሻዳይ የበጎ አድራጎት ድርጅት) is a registered non-governmental humanitarian foundation based in Wolyta Sodo, Ethiopia. The organization's mission is to sponsor education for orphans, provide emergency food distribution and community nutrition, and mobilize passionate volunteers across Ethiopia.

The digital platform delivers a seamless, high-performance web experience for donors, volunteers, and organizational staff:

  • Public Portal: Bilingual website (English and Amharic) featuring programs, news, donation channels, volunteer applications, and left-side mobile navigation.
  • Administrative Dashboard: Secure management portal for volunteer review, CMS content publication, contact inquiries, and real-time impact metrics.
  • Enterprise Backend: Modular NestJS REST API with MySQL 8.0, TypeORM, JWT authentication, and interactive Swagger documentation.

2. Technology Stack & Architecture

Tier Technology Description & Responsibility
Frontend Vanilla HTML5 / ES6+ JS Ultra-fast, zero-overhead client with SPA hash router and real-time API synchronization.
Styling & UX Custom CSS3 Design System Warm Ethiopian earth-tone palette, left-aligned off-canvas mobile drawer, glassmorphism, fluid typography.
Backend NestJS 10.x (TypeScript) Modular enterprise architecture with dependency injection, validation pipes, and exception filters.
Database Layer MySQL 8.0 / TypeORM 0.3.x Relational database with InnoDB engine, UTF8MB4 charset, indexing, and transactional integrity.
Authentication Passport.js & JWT Role-Based Access Control (RBAC) with bcrypt password hashing (10 salt rounds).
API Documentation Swagger OpenAPI 3.0 Live interactive API testing and documentation console at /api/docs.

3. Database Schema Design (elshaday_charity_db)

The system utilizes a clean, normalized relational schema with 5 primary tables:

3.1 Tables Overview

Table Name Primary Key Key Columns Purpose
admins id (UUID) name, email, password, role, isActive Administrator accounts and authorization roles.
volunteers id (INT AUTO_INCREMENT) fullName, email, phone, city, skills, status Volunteer applications and member directory.
content_items id (INT AUTO_INCREMENT) type, title, titleAm, targetAmount, currentAmount Articles, Programs, Events, News, and Gallery.
site_settings id (INT AUTO_INCREMENT) key (UNIQUE), value, group, description Dynamic contact details, banking accounts, and branding.
contact_messages id (INT AUTO_INCREMENT) name, email, phone, subject, message, status Public inquiries and internal admin follow-up notes.

4. RESTful API Endpoints Summary

HTTP Method & Route Access Level Functionality
POST /api/auth/login Public Authenticates administrator credentials and returns Bearer JWT token.
GET /api/volunteers Protected (Admin) Paginated volunteer list with status, city, and skill filters.
POST /api/volunteers/register Public Submits a new volunteer application with optional ID & CV uploads.
PATCH /api/volunteers/:id/status Protected (Admin) Updates volunteer lifecycle status (APPROVED, ACTIVE, etc.).
GET /api/content/public/programs Public Returns published charity programs and funding progress.
GET /api/content/public/settings Public Returns live organization contact details and official bank accounts.
GET /api/statistics/dashboard Protected (Admin) Returns aggregated KPI counts, funding metrics, and inquiries.

5. Quick Installation & Running Guide

5.1 Environment Setup

# 1. Clone repository
git clone https://github.com/Kehindos/elshaday-charity-asso.git
cd elshaday-charity-asso

# 2. Configure environment (backend/.env)
PORT=3000
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=
DB_DATABASE=elshaday_charity_db
DB_SYNCHRONIZE=false

# 3. Install backend dependencies
cd backend
npm install

# 4. Start Development Server
npm run start:dev
✅ Ready-to-Use URLs:
  • Public Website: http://localhost:3000/
  • Admin Portal: http://localhost:3000/admin.html
  • Interactive Swagger Docs: http://localhost:3000/api/docs
